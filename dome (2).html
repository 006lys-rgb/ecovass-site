ICT · IoT · AI
스마트 통합 제어 시스템

Dome Farm의 사계절 안정적 운영을 위해 외기 차단·환기·온습도·조도·수질을 ICT/IoT/AI로 통합 제어합니다. 3개 분야 시설을 하나의 플랫폼으로 운영합니다.

🤖 식물공장형 스마트 Dome의 핵심

일반 비닐하우스와 근본적으로 다릅니다. ECO-VASS Dome Farm은 외기를 완전히 차단하고 내부 환경을 정밀 제어하는 식물공장형 기능 구조를 갖춥니다. 온도·습도·CO₂·조도·수질이 최적 조건으로 유지되어 사계절 연중 최고 품질의 유기농 먹거리를 생산합니다. 동시에 어류 양식·식물 재배·시설 관리 3개 분야의 제어 시스템이 하나의 통합 플랫폼으로 운영됩니다. 일부 자동화된 전자 제어 방식으로 운영 인력과 비용을 최소화하면서 안전하고 효율적인 관리를 실현합니다.

🖥️

ICT 통합 제어

중앙 관리 서버에서 전체 Dome의 환경·생산·안전을 통합 모니터링하고 원격 제어합니다.

  • 중앙 통합 관리 대시보드
  • 실시간 원격 모니터링
  • 이상 감지 자동 알람
  • 운영 빅데이터 축적·분석
  • 스마트폰 앱 연동
  • CCTV 보안 통합 연동
🌡️

환경 자동 제어 (IoT)

외기 차단 후 내부 순환 환기로 최적 온습도·CO₂·조도를 유지합니다. 계절에 무관한 생산 환경을 구현합니다.

  • 순환 환풍·통기 시설 자동화
  • 온도 자동 제어 (냉난방)
  • 습도 센서 + 자동 가습
  • CO₂ 농도 최적화 제어
  • pH·DO·수온·암모니아 실시간 측정
  • 수질 이상 자동 알람
💡

LED 재배 시스템 (AI)

식물 최적 파장 LED로 일조를 보완하고 재배 효율을 극대화합니다. AI가 작물별 최적 광량을 자동 조절합니다.

  • 식물 최적 파장 LED 설치
  • AI 기반 광량 자동 조절
  • 작물별 조도 프로파일 설정
  • 에너지 효율 자동 최적화
  • 일출·일몰 시뮬레이션
  • 태양광 연계 절전 시스템
